## 👨‍💻 Sobre Mí

Con una trayectoria consolidada de más de **25 años en el sector de salud, gestión operativa y atención al cliente**, integro mi experiencia de negocio con la **ingeniería de software y el análisis de sistemas**. 

Mi enfoque profesional se centra en:
- **Traducir necesidades complejas de negocio** en arquitecturas de software claras, escalables y mantenibles.
- **Resolver problemas operativos reales**: automatización de inventarios, control de vencimientos, trazabilidad y dashboards analíticos de toma de decisiones.
- **Rigor metodológico y de calidad**: aplicación estricta de metodologías ágiles (Scrum Guía 2020), diseño centrado en el usuario (UX/UI), pruebas automatizadas (TDD) y pipelines de CI/CD.

## 🌟 Proyectos Destacados

### [🔄 Plataforma Interactiva Scrum 2026](https://github.com/JorgeTrip/2026-Scrum)
> **Simulador y mapa tridimensional del flujo metodológico Scrum basado en la Guía Oficial 2020 (UTN FRBA).**
- **Arquitectura:** React 19, TypeScript estricto, Vite, `@xyflow/react`, Tailwind CSS v4.
- **Calidad & DevOps:** 37 pruebas unitarias automatizadas con Vitest, auditoría SAST aprobada y CI/CD en GitHub Actions.
- **Aspectos Clave:** Modos guiado y libre, relaciones elásticas animadas, persistencia y swimlanes inmutables.

### [📊 Zenith Analytica (Dashboard Demo)](https://github.com/JorgeTrip/dashboard-demo)
> **Tablero de inteligencia de ventas y analítica comercial interactiva.**
- **Stack:** Next.js (App Router), TypeScript, Recharts, Leaflet, Tailwind CSS.
- **Aspectos Clave:** Filtrado multidimensional (periodo, vendedor, región), soporte dinámico Modo Claro/Oscuro y geolocalización de ventas.

### [⚡ TP-PLC-LOGO-2026](https://github.com/JorgeTrip/TP-PLC-LOGO-2026)
> **Plataforma web con monitoreo de diagrama KOP y gemelos visuales para PLC Siemens LOGO!**
- **Enfoque:** Integración de ingeniería de sistemas, automatización y visualización reactiva de estados industriales.

### [💊 FarmaKit](https://github.com/JorgeTrip/FarmaKit)
> **Solución de software para optimización operativa farmacéutica y actualización de precios.**
- **Contexto:** Nacido de la experiencia directa en farmacia hospitalaria y comunitaria para agilizar flujos críticos de trabajo.
